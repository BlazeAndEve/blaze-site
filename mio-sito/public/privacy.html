Privacy Policy - Blaze & Eve

Last updated: August 20, 2026 - blaze.eve1970@gmail.com

1. Google User Data Accessed

Our app (The Vault at blazeandeve.com/vault) requests the following Google OAuth scope: https://www.googleapis.com/auth/youtube.readonly
We use this scope solely to: (a) authenticate the user via Google Sign-In, (b) check if the authenticated user is subscribed to our YouTube channel ID UCn9mhZ2RXfrxK-C9-9_qP8w (@BlazeAndEve), (c) display the user's YouTube display name for personalization inside The Vault. We do NOT access watch history, private playlists, or other YouTube data.

2. Data Sharing, Transfer, and Disclosure

We do NOT share, transfer, sell, or disclose your Google user data to any third parties, advertisers, or other users.
Limited sharing only with service providers necessary to operate the app: - Google Firebase Authentication and Firebase Hosting (to securely manage login sessions and hosting) - Google YouTube Data API v3 (to verify subscription status) These providers are bound by their own privacy policies and process data only on our behalf. No other sharing occurs.

3. Data Protection Mechanisms

We protect sensitive Google user data using industry-standard mechanisms: - All traffic is encrypted via HTTPS/TLS 1.2+ - OAuth access tokens are handled via Firebase Authentication and are not stored in plain text on our servers; they remain in the user's browser session and Firebase secure session - No Google user data is stored in our own databases. Subscription verification is performed in real-time via API call and not persisted beyond session cache - Access is restricted to the authenticated user only

4. Data Retention and Deletion

We retain Google user data only as long as necessary to provide The Vault feature: - YouTube subscription status and display name are kept in browser memory/session storage only for the duration of your logged-in session and cleared on logout or after 1 hour of inactivity - We do not permanently retain your YouTube data on our servers - You can request complete deletion of any associated data at any time by emailing blaze.eve1970@gmail.com with subject "DELETE MY DATA". We will delete any logs/cache containing your Google user ID within 7 business days and confirm via email - You can also revoke our app's access at any time via https://myaccount.google.com/permissions
